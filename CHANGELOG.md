# Changelog

All notable changes to this project are recorded here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Each tagged release also publishes GitHub release notes,
generated by GoReleaser from the commits since the previous tag.
This file is the human-readable summary that precedes and complements them.

## [Unreleased]

### Added

- The `warm`, `list`, `debug` and `version` commands.
- URL sources: a plain-text list and an XML sitemap,
  with sitemap discovery through `robots.txt` and scope validation.
- An optional Drupal login that warms the dynamic page cache,
  followed by an anonymous stage that warms the page cache.
- Redirect detection, a tab-separated per-fetch report,
  and documented exit statuses.

No release has been tagged yet; the entries above ship in the first release.
